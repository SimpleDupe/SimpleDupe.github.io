Installation and configuration

Set up your server.

Get SimpleDupe running, choose who can use it, and customize what can be duplicated.

Install

Three quick steps

1. DownloadGet the latest JAR from the downloads page.
2. Add to serverPlace the JAR in your server's plugins folder and start Paper.
3. ConfigureEdit plugins/SimpleDupe/config.yml and messages.yml. Reload with /simpledupereload.

Requires Paper 1.21.1 and Java 21.

Commands and permissions

Use it in game

CommandPermissionDescription
/dupe [amount]simpledupe.useDuplicate the item held in your main hand.
/simpledupereloadsimpledupe.adminReload the plugin config and messages. Alias: /dupereload.

The use permission is granted to everyone by default. Reload permission is for operators by default.

Blacklist example

Choose what cannot be copied

Use material names, exact custom names, enchantment keys, or lore lines. Add :LEVEL to an enchantment to block that level and higher. Ampersand color codes are supported in names and lore.

# SimpleDupe configuration
# Maximum number of items a player can duplicate at once.
max-dupe-amount: 5

# Items matching any entry below cannot be duplicated.
blacklist:
  materials:
    - BEDROCK
    - BARRIER
    - COMMAND_BLOCK
    - STRUCTURE_BLOCK
    - JIGSAW
  names: []
  # Use an enchantment key, or KEY:LEVEL to block that level and higher.
  enchantments:
    - "SHARPNESS:6"
  lore:
    - "&ctest"
