Access control

Permissions

Choose who can duplicate items, reload the plugin, and use a higher per-player limit.

Permission nodes

PermissionDefaultWhat it allows
simpledupe.useEveryoneUse /dupe. Players still need this permission when given a custom amount limit.
simpledupe.adminOperatorsReload the plugin configuration and messages with /simpledupereload or /dupereload.
simpledupe.dupe.<number>Not grantedRaise a player's maximum dupe amount to the number in the node, overriding the configured limit for that player.

Custom amount

Give a player a higher limit

For example, if max-dupe-amount is 5, granting simpledupe.dupe.8 lets a player use /dupe 8. The config remains the default for everyone else. If multiple numeric limits are granted, the highest one is used.

/lp user <player> permission set simpledupe.dupe.8 true

This example uses LuckPerms. Grant the same permission node with your server's permission manager.
