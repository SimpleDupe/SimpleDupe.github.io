SimpleDupe features

Control the details.

Keep item duplication straightforward while setting the rules that make sense for your server.

01 / LIMITS

Choose the copy limit

Set max-dupe-amount in the config and let players duplicate one item or a chosen amount up to that limit.

02 / MATERIALS

Block item types

Keep materials such as Bedrock, Barriers, or Command Blocks off the duplication list.

03 / ITEM DETAILS

Match names and lore

Block items by exact custom name or lore line, including legacy color codes such as &ctest.

04 / ENCHANTMENTS

Set enchantment thresholds

Block an enchantment at every level, or use a threshold such as SHARPNESS:6 to block level 6 and above.

05 / ITEM DATA

Preserve the item

SimpleDupe clones the held stack, preserving its name, lore, enchantments, and item data.

06 / INVENTORY

Handle full inventories

Items that do not fit in the inventory are dropped naturally at the player's location.

Configuration

Rules live in config.yml

Use separate lists for each kind of blacklist rule. Names and lore support ampersand color codes; enchantment levels are inclusive thresholds.

blacklist:
  materials:
    - BEDROCK
  names: []
  enchantments:
    - "SHARPNESS:6"
  lore:
    - "&ctest"
